# ТОПСТАНКИ — статическая копия для редактирования

Источником выступает https://topstanki.ru/.

Создана независимая ветка `topstanki-clone`, не затрагивающая рабочую ветку `main` существующего сайта «Все о листогибах».

## Сборка
Скрипт `mirror_site.py` обходит публичные страницы сайта, скачивает HTML, CSS, JS и изображения (в пределах заданного лимита), переписывает внутренние ссылки и сохраняет страницы в `mirror/`. Рабочий процесс GitHub Actions запускается при изменении скрипта и может обновлять зеркало автоматически.

Для локальной сборки:

```bash
pip install -r requirements.txt
python mirror_site.py
python -m http.server 8000
```

Откройте http://localhost:8000/mirror/ .

## Ограничения
Это статический архив публичной части, **не полноценный перенос WordPress**. Корзина, заказы, серверный поиск, формы и личные кабинеты не будут работать без серверной части и базы. Некоторые картинки и страницы могут быть недоступны при обходе. Генератор переписывает `mirror/` при повторном запуске, поэтому перед редактированием сохраняйте собственные изменения в отдельных шаблонах.

## Публикация
Лучше создать **новый отдельный репозиторий** и перенести туда файлы этой ветки, затем включить GitHub Pages из корня ветки. Не меняйте Pages-настройки текущего репозитория: в нём уже размещён другой сайт.

Чтобы полностью перенести интернет-магазин и редактировать через админку, нужен экспорт WordPress, база данных, каталог `wp-content` и конфигурация плагинов. Никогда не загружайте пароли, данные заказов и персональные данные в публичный GitHub.
