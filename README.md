# BDC3200 — симулятор панелегиба

Проект учебного симулятора гибки листового металла.

- `index.html` — автономный HTML-симулятор, открывается локально в браузере.
- `Panel-Bender-Knowledge-Base.md` — исследовательская база, технология гибки и источники.

## Запуск

Скачайте `index.html` из этой ветки и откройте его в браузере. Сборка и сервер не требуются.

## GitHub Pages

Текущая ветка не обязательно опубликована через GitHub Pages. Настройка выполняется в **Settings → Pages**; переключение Pages на эту ветку может отключить сайт, ранее опубликованный из другой ветки данного репозитория. Поэтому Pages автоматически не переключались.

## Предупреждение

Приложение — геометрическая симуляция, не заводской контроллер. Кинематика, пределы ходов и столкновения требуют проверки по оборудованию. Последний запрос о порядке гибов «сначала 20 мм от края, затем 100 мм» не следует считать проверенным в этой сохранённой версии до отдельного тестирования.

Ветка `bdc3200-simulator` независима от основной `main`.
