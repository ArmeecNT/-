# TOPSTANKI — 3D-модель листогибочного пресса

Откройте `index.html` в современном браузере. Установка и сервер не нужны.

Вращение — левая кнопка мыши, перемещение — правая, масштаб — колесо. Есть переключение рабочей длины, ход балки и экспорт OBJ / OpenSCAD.

## Параметры версии 3.3

- Рабочая длина: 1600, 2000, 2500 или 3200 мм.
- Просвет между стенками: рабочая длина минус 600 мм.
- Стол: 210 мм по глубине.
- Зев: 350 мм.
- Ход цилиндров: 200 мм.
- Раскрытие без инструмента: 425 мм; нижний зазор: 225 мм.
- Глубина основания: 2000 мм.
- Высота: 2950 мм; боковины: 40 мм.

Модель схематичная, расчёт прочности не выполнен. Задний упор из отдельных иллюстраций в эту версию 3D ещё не перенесён. Для длины 1600 мм гидростанция скрыта из-за недостаточного пространства.

## Исходники

`build.py` содержит геометрию и интерфейс; `vendor/three.min.js` — встроенная библиотека Three.js. Пересборка: `python3 build.py`. Результат — автономный `index.html`.
